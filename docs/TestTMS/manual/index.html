01

소개

Introduction

TestTMS는 TMS_F(Thermal Monitoring System) 프로그램 개발 및 검증을 위한 TMS_F 측 클라이언트 시뮬레이터입니다. SimulationTMS(서버)에 TCP 클라이언트로 접속하여 TMS TCP 프로토콜을 검증하고, Spot/Area 온도를 시각화하며, SetTempInfo/SetCamInfo 명령 송신을 테스트합니다.

최대 21대 카메라

IP/Port 개별 설정, Add/Remove로 동적 관리

TCP 이중 채널

Port 5000 Polling / Port 5001+ Push 수신

Sp/Ar 요약 그리드

전체 카메라의 Spot/Area 온도 한눈에 확인

Iron 열화상 렌더링

실시간 Iron 컬러맵 프리뷰

Set 명령 테스트

SetTempInfo / SetCamInfo 직접 송신

자동 업데이트

Velopack 기반 원클릭 업데이트

지원 환경

항목내용
OSWindows 10 / 11 (64-bit)
프레임워크.NET 8.0 (WPF, win-x64)
설치 경로C:\FlexPower\TestTMS\
통신TCP/IP — Port 5000 (Control), 5001~5005 (Monitor)
TMS 모델TMS_350, 160×120
02

설치 및 실행

Installation & Launch

설치 방법

  1. 설치 프로그램 다운로드
    Help 메뉴 → Download Installer 또는
    https://greenpowersw.github.io/Pages-releases/TestTMS/ 에서 최신 버전의 TestTMS-{version}-Setup.exe 다운로드
  2. 설치 실행
    다운로드한 .exe 파일을 실행합니다. 설치 경로: C:\FlexPower\TestTMS\
  3. 프로그램 시작
    바탕화면 또는 시작 메뉴의 TestTMS 아이콘을 더블클릭합니다.

설치 구조

C:\FlexPower\TestTMS\
├── Update.exe          # Velopack 업데이트 런처
├── current\            # 실행 파일 (TestTMS.exe 등)
├── Config\             # 사용자 설정 (업데이트 후에도 보존)
│   └── AppSettings.json
└── packages\           # 업데이트 패키지 캐시

설정 보존: 업데이트 시 Config\AppSettings.json은 덮어쓰지 않으므로 기존 카메라 목록과 설정이 유지됩니다.

04

빠른 시작

Quick Start

사전 조건: SimulationTMS(서버) 또는 실제 TMS 카메라가 네트워크에서 동작 중이어야 합니다.

  1. 카메라 IP/Port 설정
    좌측 카메라 목록에서 각 카메라 행의 IP 주소와 Port를 클릭하여 직접 수정합니다.
    기본값: 127.0.0.1 : 5000
  2. Connect
    카메라 행의 Connect 버튼을 클릭하거나, 상단의 Connect All 버튼을 사용합니다.
    연결 성공 시 상태 인디케이터(●)가 녹색으로 변경됩니다.
  3. Start Polling
    Start Polling 버튼을 클릭합니다. 200ms 주기로 ReqImage 요청이 시작되며, 중앙 패널에 온도 데이터와 열화상 이미지가 실시간으로 갱신됩니다.
  4. 데이터 확인
    Sp/Ar Summary 그리드에서 전체 현황을 확인하고, 행 클릭으로 카메라를 선택하면 Detail Table과 Thermal Preview가 해당 카메라 데이터로 갱신됩니다.

연결 후 IP/Port 잠금: Connect 상태에서는 IP/Port 입력 필드가 자동으로 비활성화됩니다. Disconnect 후 수정할 수 있습니다.

06

Set 명령

Set Commands

선택된 카메라에 SetTempInfo와 SetCamInfo 명령을 직접 송신하여 카메라 설정을 변경할 수 있습니다.

SetTempInfo — 온도 경보 임계값 설정

Area별 Warning/Alarm 임계값을 설정합니다. 테이블에서 직접 값을 입력한 후 Apply to Camera를 클릭합니다.

컬럼설명
AreaArea 인덱스 (Ar01~Ar10)
Use해당 Area 활성화 여부
Warn (°C)Warning 임계 온도
Alarm (°C)Alarm 임계 온도

SetCamInfo — 카메라 파라미터 설정

항목설명기본값
Emissivity방사율 (1~100)100
Gain ModeHIGH (0) / LOW (1)HIGH (0)
FFC Period (ms)FFC 자동 실행 주기 (밀리초)30000

주의: Set 명령은 카메라가 Connected 상태일 때만 동작합니다. 연결 전에는 Apply 버튼이 비활성화됩니다.

08

자동 업데이트

Auto Update

TestTMS는 Velopack 기반 자동 업데이트를 지원합니다. 업데이트 서버: https://greenpowersw.github.io/Pages-releases/TestTMS/

업데이트 확인 방법

  • 시작 시 자동 확인 — Preferences의 Check for updates on startup이 ON이면 앱 시작 시 자동 확인
  • 수동 확인 — Help 메뉴 → Check for Updates...

업데이트 절차

  1. 새 버전 감지 시 업데이트 알림 대화상자 표시
  2. 예 클릭 시 백그라운드 다운로드 시작 (로그 패널에서 진행률 확인)
  3. 다운로드 완료 후 자동으로 업데이트 적용 및 재시작

개발 모드 제한: 설치 프로그램(C:\FlexPower\TestTMS\current\)으로 실행되지 않은 경우 자동 업데이트 기능이 비활성화됩니다.

설치 파일 직접 다운로드

업데이트가 어려운 환경에서는 Help 메뉴 → Download Installer로 설치 파일을 직접 다운로드할 수 있습니다.
