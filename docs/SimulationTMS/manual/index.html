01

소개

Introduction

SimulationTMS는 TMS_F(Thermal Monitoring System) 프로그램의 테스트 및 개발 지원을 위한 열화상 카메라 시뮬레이터입니다. 실제 TMS 열화상 카메라(TMS_350, 160×120)가 연결된 것처럼 TCP/IP 프로토콜로 영상 및 온도 데이터를 전송하여, TMS_F의 기본 동작 검증과 알람 테스트를 수행합니다.

최대 21대 카메라

TMS_350, 160×120 해상도의 가상 카메라

독립 TCP 서버

카메라별 비동기 TCP 서버 지원

온도 패턴

None / Gradient / Random + Hot Spot

Area Override

Warning/Alarm 트리거 테스트

실시간 프리뷰

Iron 컬러맵 기반 열화상 렌더링

다국어

영어 / 한국어 즉시 전환

02

설치 및 실행

Installation

설치 절차

  1. 배포 페이지(Pages)에서 최신 인스톨러 다운로드
  2. SimulationTMS_vX.X.X_Build_YYYYMMDD_HHMM_Setup.exe 실행
  3. 설치 완료 후 자동 실행됩니다.

설치 경로

C:\GreenPower\SimulationTMS\
  ├── Update.exe       # Velopack 업데이트 관리자
  ├── current\         # 실행 파일
  ├── Config\          # 사용자 설정 (업데이트 시 보존)
  └── packages\        # 업데이트 패키지

Tip. Config/ 폴더의 사용자 설정은 업데이트 시 보존됩니다. 기본값은 AppSettings.default.json, 사용자 수정값은 Config/AppSettings.json에 저장됩니다.

04

빠른 시작

Quick Start
  1. 카메라 목록에서 사용할 카메라를 체크REQUIRED
  2. 상단 툴바의 Start All 버튼 클릭 → 체크된 카메라만 TCP 서버 시작
  3. TMS_F 등 클라이언트에서 해당 IP/Port로 접속
  4. 실시간 Thermal Preview와 로그로 동작 확인
  5. 테스트 완료 후 Stop All로 서버 종료

Tip. 카메라별 IP/Port는 목록 UI에서 직접 편집하며 자동 저장됩니다. 기본은 127.0.0.1:5000부터 순차 할당됩니다.

05

온도 패턴

Temperature Pattern

메인 화면의 Pattern Expander에서 선택된 카메라의 배경 온도 분포를 설정합니다.

패턴설명
None평탄한 Base Temperature (노이즈 및 HotSpot만 반영)
Gradient선택된 방향(상/하/좌/우/원형)으로 Base ~ Base+Range 선형 변화. Reverse 옵션으로 반전 가능
Random픽셀별 Base ± Range/2 무작위 분포

파라미터

  • Base Temperature — 기본 온도 (℃)
  • Range — 패턴이 유발하는 온도 변동 폭 (℃)
  • Direction — Gradient 방향 (Top / Bottom / Left / Right / Circle)
  • Reverse — Gradient 반전

각 Expander에는 Apply to Enabled CAMs / Apply to All CAMs 버튼이 있어 현재 설정을 일괄 적용할 수 있습니다.

06

Hot Spots

Local Hot Regions

국소 고온 영역을 시뮬레이션합니다. 카메라당 최대 5개 등록 가능합니다.

파라미터

  • X, Y — 중심 좌표 (0~159, 0~119)
  • Size — 반경 (픽셀, 가우시안 분포)
  • Delta T — 배경 대비 온도 상승 (℃)
  • Enabled — 개별 On/Off

DataGrid UI에서 행을 추가/삭제하며, 변경은 즉시 프레임 생성에 반영됩니다.

07

Area 알람 오버라이드

Area Alarm Override

TMS_F 쪽 Area(관심영역)의 온도를 강제로 설정하여 Warning/Alarm 트리거를 테스트합니다.

  1. Area 번호 선택 (1~10)
  2. 현재 온도(Current)와 Override 목표값(Target) 확인
  3. Apply 버튼 → 해당 Area 픽셀들의 온도를 Target 값으로 강제
  4. Reset 버튼 → 오버라이드 해제 (원래 패턴으로 복귀)

Area 좌표 및 임계값(Warning1 / Warning2 / Alarm)은 SetTempInfo 패킷을 통해 TMS_F로부터 수신되며, Thresholds Expander에서 직접 편집할 수도 있습니다.

Auto Update

TMS 프로토콜

TCP Protocol Summary
  • 모델: TMS_350 (0x02), 160×120 해상도
  • 온도 형식: Kelvin × 100 → raw = (celsius + 273.15) × 100
FunctionCode응답 크기설명
ReqImage0x0138,619 B프레임 + Spot + Area + WinAlm + Tilt
ReqCamInfo0x08125 B카메라 정보
ReqTempInfo0x03198 BSpot/Area 온도 정보
SetTempInfo0x108 B (ACK)Area 임계값 설정 수신
SetCamInfo0x138 B (ACK)카메라 정보 설정 수신

문제 해결

Troubleshooting

Start 시 특정 카메라가 Error 상태

  • 해당 Port가 이미 사용 중일 수 있음 → 다른 Port 사용 또는 충돌 프로세스 종료
  • 방화벽이 TCP Listen을 차단한 경우 허용 규칙 추가
  • 나머지 카메라는 정상 시작되며, 실패한 카메라만 Error 표시 (Graceful)

TMS_F에서 연결은 되지만 영상이 이상함

  • Base Temperature / Range 값 확인 (절대 영도 근처이면 화면이 깨짐)
  • Pattern이 None이면서 HotSpot도 없으면 단색으로 보임 → 정상
  • 로그 패널에서 요청 Function Code 수신 여부 확인

자동 업데이트가 동작하지 않음

주의. 구 버전(v1.0.5 이하)은 업데이트 URL이 이전 도메인으로 고정되어 있어 수동 재설치가 필요할 수 있습니다.

  • 인터넷 연결 및 방화벽 상태 확인
  • Velopack 설치 모드(C:\GreenPower\SimulationTMS\current\)가 아닌 경우 자동 업데이트 비활성
